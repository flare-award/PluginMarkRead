# MarkRead — плагин для Vencord

Плагин ставит ✅ / ✅✅ после времени ваших сообщений в личных переписках.
Две галочки означают, что клиент собеседника подтвердил реальный показ сообщения на экране.

## Установка

Полная инструкция для Windows 10: [`../docs/install-windows.md`](../docs/install-windows.md).

Коротко:

```powershell
git clone https://github.com/Vendicated/Vencord.git Vencord
cd Vencord
pnpm install --frozen-lockfile
# скопируйте папку markRead из этого репозитория в src/userplugins/markRead
pnpm build
pnpm inject
```

После перезапуска Discord включите плагин в **Настройки → Vencord → Plugins → MarkRead**.

## Настройки

| Настройка | По умолчанию | Описание |
| --- | --- | --- |
| Receipt exchange | выкл. | Подключение к relay и обмен подтверждениями. Пока выключено, плагин ничего не передаёт. |
| Share read receipts | выкл. | Отправлять свои подтверждения о прочитанном. Без этого вы получаете подтверждения, но не делитесь своим состоянием. |
| Relay URL | пусто | `wss://host/ws`. `ws://` разрешён только для localhost. Учётные данные и fragment в URL запрещены. |
| Dwell time | 1,5 с | Сколько сообщение должно непрерывно находиться на экране. Диапазон 250 мс — 10 с. |
| Show sent checks | вкл. | Показывать одну галочку до получения подтверждения. |
| Indicator size | 14 px | Размер индикатора. |
| Read colour | Discord accent | Цвет подтверждённого прочтения: акцент, зелёный или синий. |
| Show read time | выкл. | Показывать в подсказке локальное время получения подтверждения. |

Настройки применяются сразу. Изменение URL relay или включение обмена перезапускает соединение.

## Поведение индикатора

| Состояние | Вид | Значение |
| --- | --- | --- |
| Своё сообщение, обмен включён | ✅ | Сообщение отправлено. Подтверждения ещё нет. |
| Получено проверенное подтверждение | ✅✅ | Собеседник видел именно эту версию сообщения. |
| Сообщение отредактировано после прочтения | ✅✅ серым | Прочитана старая версия; новая не подтверждена. |
| Обмен выключен / нет relay / собеседник не в сети | ✅ | Причина указана в подсказке. |

Подсказка при наведении объясняет, почему подтверждения нет, и всегда напоминает: отсутствие подтверждения не означает, что сообщение не прочитано.

## Когда отправляется подтверждение

Подтверждение создаётся фоновым наблюдателем в accessory каждого входящего сообщения:

1. сообщение от собеседника (не от бота и не от вас);
2. включён обмен и отправка подтверждений;
3. канал не отключён через контекстное меню;
4. канал выбран, окно Discord видимо и в фокусе, нет модального диалога;
5. строка сообщения видна минимум на 96 px или целиком (для коротких);
6. все условия выполняются непрерывно не меньше dwell-времени.

Любое нарушение сбрасывает таймер. Перерисовка, прокрутка и повторная загрузка не создают дублей: перед подписью проверяется журнал отправленных подтверждений, а relay дедуплицирует по `receiptId`.

## Контекстное меню

В контекстном меню личного канала (**правый клик по DM**) есть пункт **Disable MarkRead confirmations**. Он отключает и отправку, и приём подтверждений для этой переписки. Вернуть можно там же или в настройках плагина.

## Хранение данных

| Ключ DataStore | Содержимое |
| --- | --- |
| `markread.identity.v1` | Неизвлекаемый ключ ECDSA P-256 (IndexedDB). |
| `markread.identity.jwk.v1` | Резервный вариант, если среда не поддерживает неизвлекаемые ключи. |
| `markread.device.v1` | Случайный UUID устройства. |
| `markread.receipts.v1` | Проверенные подтверждения (id сообщения/канала, время). |
| `markread.sent.v1` | Журнал отправленных подтверждений для защиты от дублей. |
| `markread.optout.v1` | Отключённые каналы. |
| `markread.pins.v1` | Отпечатки ключей собеседников (TOFU). |

Удалить данные можно в панели настроек плагина. «Delete everything» также удаляет ключ и device id.

## Диагностика

- **Status: Not configured** — пустой Relay URL.
- **Status: Reconnecting** — сервер недоступен; в подсказке будет время следующей попытки и код ошибки.
- **Last error: key_mismatch** — на relay уже зарегистрирован другой ключ для вашего Discord ID. Попросите оператора relay выполнить `--reset-user <ваш_id>`.
- **Last error: auth_failed** — подпись не прошла проверку. Сбросьте идентичность в настройках и попросите оператора очистить регистрацию.
- **Собеседник «not registered»** — он не подключался к этому relay или использует другой сервер.
- **Подтверждения не приходят, хотя собеседник онлайн** — проверьте, что у него включён **Share read receipts**, а сообщение действительно было на экране нужное время.

Логи плагина доступны в консоли Discord (`Ctrl+Shift+I`) с префиксом `[MarkRead]`.
